# D.B. Cooper: style references v001 (22 Nov 2026)

These use the same gouache style as NOKAS. They were made with `nano_banana_2_1` at 2k and 16:9, using NOKAS BG2 (`24d23986…`) or BG3 (`d691a1fb…`) as the brushwork reference. The prompts are in `requests.json`. The full PNGs are in `png/`, which is gitignored; they can be re-downloaded from the Higgsfield history. Review copies are in `final_jpg/`, and a contact sheet is in `style_refs_v001_sheet.jpg`.
