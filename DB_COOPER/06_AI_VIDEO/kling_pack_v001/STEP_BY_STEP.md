# Kling: step by step (8 clips, about 20 minutes)

The buttons may be named slightly differently in your version of Kling. Look for the closest match.

## Before you start (once)
1. Save the 8 images from the chat to your phone or computer: **K01_102.jpg** through **K08_1301.jpg**.
2. Open **klingai.com** and log in.
3. Go to **Video**, then **Image to Video**.

## The same settings for every clip
Set these once and check they're still set for each new clip:
- Length: **5 s**
- Aspect ratio: **16:9**
- Number of videos/outputs: **1**
- Sound/audio: **off**
- Mode/quality: **Standard** (the cheapest; 720p is fine)
- If you see a **Creativity / Relevance** slider: set it toward the image, about **0.6–0.7**.

**Negative prompt.** Paste it into the "Negative prompt" field for every clip. If there's no such field, skip it.
```
text, letters, words, numbers, logos, signs, subtitles, watermark, faces, face turning toward camera, people walking, extra people, hands moving, morphing, warping, style change, photorealistic, 3D render, camera shake, fast motion, flicker
```

## For each clip: 5 steps
1. **Upload** the image with the right number.
2. **Paste** the clip's prompt (below) into the prompt field.
3. Check that the **negative prompt** and **settings** are still there.
4. Click **Generate**.
5. When it's finished: **download** it and rename the file to **K01.mp4**, **K02.mp4** and so on.

Only one try per clip. If one looks bad, download it anyway; I'll judge it.
